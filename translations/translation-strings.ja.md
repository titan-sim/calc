# 번역용 텍스트 목록 (한국어 → 일본어)

다이노 뮤턴트 시뮬레이터 사이트 전체의 사용자 노출 텍스트를 한국어 원문과 일본어 번역으로 정리한 표입니다. `{placeholder}` 형태는 실행 중에 채워지는 변수 자리이므로 그대로 유지했습니다. 같은 내용이 `translation-strings.json`(한국어 원문)과 `translation-strings.ja.json`(번역)에 키-값 형태로도 들어있습니다.
